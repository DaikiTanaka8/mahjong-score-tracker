# 機能要件

麻雀の成績を記録・管理する Web アプリの要件定義書(第1段階: MVP)。

## 1. 目的

友人・仲間内で行った麻雀の対局結果を記録し、プレイヤーごとの成績を集計して見られるようにする。

## 2. 前提

| 項目 | 内容 |
|------|------|
| 対象 | 4人麻雀 |
| ルール | 最高位戦ルール |
| 利用者 | 仲間内で複数人が利用する |
| ログイン | なし(名前だけ登録する) |
| 公開範囲 | AWS 上では自分の IP のみ許可する(課題の動作確認用) |

### 2.1 麻雀ルール(スコア計算の前提)

| 項目 | 内容 |
|------|------|
| 持ち点 | 30,000点 |
| 返し点 | 30,000点(オカなし) |
| ウマ | 10-30(1位 +30、2位 +10、3位 −10、4位 −30) |

### 2.2 スコア計算

```
最終スコア = (素点 − 30,000) ÷ 1,000 + ウマ
```

- 素点の単位は100点とする(例: 32,500点)。そのため、最終スコアは小数第1位まで出る。
- 最終局が流局して供託(場に残った点棒)が残ったまま終了することがあるため、対局ごとに「供託」を記録する。供託がなければ 0 とする。
- **4人の素点の合計 + 供託 = 120,000点** でなければならない(入力時にチェックし、満たさない場合は登録できない)。
- 供託が 0 のとき、4人の最終スコアの合計は 0 になる。供託が残った対局では、供託はだれの素点にもならないため、合計は 0 にならない(合計 = −供託 ÷ 1,000)。
- 供託が 0 でない対局は、「供託が残って終了した対局」として判別できる。

計算例:

| 順位 | 素点 | 計算 | 最終スコア |
|------|------|------|-----------|
| 1位 | 42,500 | (42,500 − 30,000) ÷ 1,000 + 30 | +42.5 |
| 2位 | 31,000 | (31,000 − 30,000) ÷ 1,000 + 10 | +11.0 |
| 3位 | 28,000 | (28,000 − 30,000) ÷ 1,000 − 10 | −12.0 |
| 4位 | 18,500 | (18,500 − 30,000) ÷ 1,000 − 30 | −41.5 |

### 2.3 同点のときの扱い

素点が同じ人がいる場合は、順位を「平均順位」で表記し、ウマ(順位点)を分け合う。

- 同点の人たちが占める順位を平均して、その人たち全員の順位とする(例: 1位と2位が同点なら、2人とも 1.5位)
- 同点の人たちが占める順位のウマを合計し、人数で割ったものを、全員のウマとする
- 席順による優劣はつけない

| 同点のパターン | 順位の表記 | 各自のウマ | 各自の順位回数の増え方 |
|---------------|-----------|-----------|----------------------|
| 1位・2位が同点 | 1.5位 | (+30 +10) ÷ 2 = +20 | 1位 +0.5、2位 +0.5 |
| 2位・3位が同点 | 2.5位 | (+10 −10) ÷ 2 = 0 | 2位 +0.5、3位 +0.5 |
| 3位・4位が同点 | 3.5位 | (−10 −30) ÷ 2 = −20 | 3位 +0.5、4位 +0.5 |
| 1位〜3位の3人が同点 | 2位 | (+30 +10 −10) ÷ 3 = +10 | 1位・2位・3位に各 +1/3 |
| 2位〜4位の3人が同点 | 3位 | (+10 −10 −30) ÷ 3 = −10 | 2位・3位・4位に各 +1/3 |
| 4人全員が同点 | 2.5位 | (+30 +10 −10 −30) ÷ 4 = 0 | 1位〜4位に各 +0.25 |
| 1位・2位の同点と、3位・4位の同点が同時 | 上の2人が1.5位、下の2人が3.5位 | 上の2人 +20、下の2人 −20 | 上の2人は1位・2位に各 +0.5、下の2人は3位・4位に各 +0.5 |

どのパターンでも、ウマは割り切れて整数になる。

順位回数の増え方は「同点の人数で等分する」という考え方で、1対局あたりの合計は常に4(1人あたり1)になる。

計算例(1位・2位が同点):

| 順位 | 素点 | 計算 | 最終スコア |
|------|------|------|-----------|
| 1.5位 | 36,000 | (36,000 − 30,000) ÷ 1,000 + 20 | +26.0 |
| 1.5位 | 36,000 | (36,000 − 30,000) ÷ 1,000 + 20 | +26.0 |
| 3位 | 28,000 | (28,000 − 30,000) ÷ 1,000 − 10 | −12.0 |
| 4位 | 20,000 | (20,000 − 30,000) ÷ 1,000 − 30 | −40.0 |

### 2.4 同点のときの成績集計

成績集計の「1〜4位の回数」「トップ率」「ラス率」は、2.3 の「順位回数の増え方」で按分した値を使う。平均順位は、1.5位などの小数をそのまま使って平均する。

- 1位の回数 = 1位が 1回の対局 +1、1.5位の対局 +0.5 …(以下同様に合計する)
- 回数は小数になることがある。3人同点の 1/3 は、画面では小数第2位まで表示する

### 2.5 要確認事項

なし(現時点)。

## 3. 機能一覧(MVP)

| No. | 機能 | 説明 |
|-----|------|------|
| F01 | プレイヤー登録 | 名前を入力してプレイヤーを登録できる |
| F02 | プレイヤー編集 | 登録済みのプレイヤーの名前を変更できる |
| F03 | プレイヤー削除 | プレイヤーを論理削除できる。過去の対局は残り、「削除されたプレイヤー」として表示する。削除後は新しい対局に選べなくなる |
| F04 | 対局登録 | 対局日と、4人分のプレイヤー・素点、供託を入力して登録できる。順位と最終スコアは自動計算する |
| F05 | 対局一覧 | 登録済みの対局を新しい順に一覧表示できる |
| F06 | 対局編集 | 登録済みの対局を編集できる |
| F07 | 対局削除 | 登録済みの対局を削除できる |
| F08 | 成績集計 | プレイヤーごとの成績を一覧表示できる |
| F09 | プレイヤー詳細 | プレイヤーを選ぶと、そのプレイヤーの過去の対局履歴と成績(順位の回数、トップ率など)を表示できる |

### 3.1 登録できる情報

#### プレイヤー

| 項目 | 必須/任意 | 説明 |
|------|----------|------|
| 名前 | 必須 | 最大20文字。削除されていないプレイヤーの間で重複不可 |

プレイヤーを削除しても、過去の対局のデータは残る。削除したプレイヤーは、対局の履歴では「削除されたプレイヤー」と表示する。

#### 対局

| 項目 | 必須/任意 | 説明 |
|------|----------|------|
| 対局日 | 必須 | 対局を行った日。同じ日に複数の対局を登録できる(重複チェックはしない) |
| 参加者(4人) | 必須 | 4人全員の選択が必要。同じプレイヤーを重複して選べない。削除済みのプレイヤーは選べない |
| 素点(4人分) | 必須 | 4人全員の入力が必要。100点単位 |
| 供託 | 必須 | 場に残った点数。100点単位。残っていなければ 0。0でない場合は「供託が残って終了した対局」を意味する |

登録できる条件(満たさない場合は登録できない):
- 参加者が4人選択されている
- 素点が4人分入力されている
- 4人の素点の合計 + 供託 = 120,000点

順位と最終スコアは入力せず、素点から自動計算する。

### 3.2 成績集計の項目

| 項目 | 説明 |
|------|------|
| 対局数 | 参加した対局の数 |
| 通算スコア | 最終スコアの合計 |
| 最高素点 | 1回の対局での素点の最大値(例: 58,000)。追加の入力は不要で、登録済みの素点から求める |
| 平均順位 | 順位の平均 |
| 1〜4位の回数 | 各順位になった回数(同点は按分した値。小数になることがある) |
| トップ率 | 1位の回数 ÷ 対局数 |
| ラス率 | 4位の回数 ÷ 対局数 |

同点の扱いは「2.3 同点のときの扱い」「2.4 同点のときの成績集計」を参照。

プレイヤー詳細画面(S05)では、上の集計項目に加えて、そのプレイヤーの対局履歴(対局日、順位、素点、最終スコア、同卓者の名前・順位・素点)を表示する。同卓者の情報は、どの対局だったかを思い出すために表示する。
## 4. 画面一覧

| No. | 画面名 | 説明 |
|-----|--------|------|
| S01 | 成績一覧画面(トップ) | プレイヤーごとの成績集計を表示する |
